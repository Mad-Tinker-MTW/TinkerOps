## Numbering note (PMD-003 intentionally vacant)

There is no PMD-003. The suite originally followed the large-project six-document numbering (Charter 001, Scope 002, WBS 003, Schedule 004, Risk 005, Stakeholder 006). During the 2026-06 documentation pass the project was reclassified as focused: the standalone Scope document was dropped (scope is covered by the Charter and the WBS), and the WBS was renumbered from PMD-003 to PMD-002. The Schedule, Risk, and Stakeholder documents kept their original 004/005/006 numbers to avoid churning their cross-references and Obsidian mirrors.

The result is a deliberate gap at PMD-003. The five documents above are the complete, current suite. This is recorded here so the gap reads as intentional, not as a missing document. Resolved 2026-06-20 (/doc-project).
